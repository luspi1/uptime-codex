# Профиль пользователя

Страница `/profile` доступна после входа через пункт «Мой профиль» в меню тулбара. Она показывает email (только чтение) и позволяет изменить имя. После сохранения имя обновляется в меню и остаётся доступным после перезагрузки страницы.

## Контракт API

Объект пользователя во всех ответах авторизации и `GET /api/auth/me` теперь содержит `name: string`. У существующих и новых пользователей имя изначально пустое. При запуске backend AutoMigrate добавляет колонку `users.name` с пустым значением по умолчанию.

`PATCH /api/auth/me` требует `Authorization: Bearer <JWT>` и JSON `{"name":"Анна Иванова"}`. Пользователь определяется по JWT. Пробелы по краям удаляются; имя должно содержать от 1 до 100 Unicode-символов. Email, пароль и другие поля менять через этот метод нельзя.

Успех: HTTP 200 и `{"id":1,"email":"user@example.com","name":"Анна Иванова"}`. Имя сохраняется в PostgreSQL. Ошибки используют общий формат `{"error":{"code":"...","message":"..."}}`: некорректное тело или имя — 400 `invalid_request`, отсутствующий или недействительный JWT — 401 `invalid_token`, ошибка базы — 500 `internal_error`. CORS разрешает метод PATCH для настроенного CLIENT_ORIGIN.

Клиент повторяет запрос после обновления истёкшего access JWT. При ошибке сохранения введённое имя остаётся в форме для повторной попытки.

## Проверки

Frontend: `npm test`, `npm run typecheck`, `npm run build`, `npm run test:e2e`. Браузерные тесты проверяют переход из меню, просмотр email, валидацию, повторное сохранение после сетевой ошибки, обновление меню, перезагрузку и перенаправление на вход. Снимки экрана: `frontend/test-results/profile-desktop.png` и `frontend/test-results/profile-mobile.png`.

Backend: `go test ./...`, `go build ./cmd/server`. Для интеграционного теста сохранения задайте `TEST_DATABASE_URL` с адресом отдельной тестовой PostgreSQL и запустите `go test ./internal/auth -run TestProfilePersistence -v`. Тест выполняет миграцию, проверяет PATCH, последующий GET и данные в базе, а также неизменность второго пользователя; тестовые строки откатываются транзакцией. Без этой переменной интеграционный тест пропускается.
