# Авторизация на frontend

## Кратко

Подключить Next.js к существующему API авторизации Go. Добавить адаптивные формы регистрации и входа, а также личную страницу с email и выходом.

## Контракт и принятые решения

- Браузер отправляет запросы на `${NEXT_PUBLIC_API_URL}/api/auth` с `credentials: "include"`. Локальный адрес backend по умолчанию — `http://localhost:8080`.
- `POST /register` и `POST /login` принимают email и пароль, возвращают пользователя и access JWT. Refresh-токен остаётся в HTTP-only cookie.
- Access JWT хранится только в памяти. После перезагрузки клиент вызывает `POST /refresh`, затем `GET /me` с `Authorization: Bearer <JWT>`. Одновременные попытки обновить токен используют один запрос.
- `POST /logout` отзывает сессию; при успешном ответе клиент очищает локальное состояние. При ошибке сети показывает сообщение и позволяет повторить выход.
- Личная страница пока показывает только email и выход. Подтверждение email и восстановление пароля не входят в задачу: backend не предоставляет эти методы.
