# Правила для бэкенда

## Структура

В этом каталоге находится HTTP-сервис на Go. Файл `cmd/server/main.go` служит точкой входа и сейчас регистрирует обработчик корневого пути. По мере развития сервиса выносите повторно используемый код в отдельные пакеты этого модуля, а код запуска оставляйте в `cmd/server/`.

## Разработка и проверка

В модуле указана версия Go 1.25. Выполняйте команды из этого каталога:

- `go run ./cmd/server` — запустить сервер на `http://localhost:8080`.
- `go test ./...` — запустить тесты всех пакетов.
- `go build ./cmd/server` — проверить сборку сервера.

## Стиль кода и тесты

Форматируйте изменённые файлы Go с помощью `gofmt`. Используйте имена пакетов в нижнем регистре и короткие, понятные идентификаторы. Размещайте тесты рядом с проверяемым кодом в файлах `*_test.go`, называйте тестовые функции `Test...`. Сейчас тестов и порога покрытия нет; добавляйте предметные тесты для новых обработчиков и бизнес-логики и выполняйте `go test ./...` перед отправкой изменений.
